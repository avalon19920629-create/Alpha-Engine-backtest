# Dow Momentum Study v0.1

保存済み価格だけで、確定スイング安値割れに既存モメンタムを超える追加情報があるかを検討する研究用イベントスタディです。仮説を肯定することが成功条件ではありません。同じ固定データと事前仕様から、警報・比較群・将来成績・反例を再検証できることが目的です。

これはダウ理論に着想を得た簡易スイング診断です。古典的ダウ理論の厳密な再現、売買シミュレーション、投資助言、独立したアウトオブサンプル検証ではありません。既存エンジン、Research Runner、運用ノート、原本Parquetを変更しません。新規市場データ取得・Live Screener起動・自動注文・既存スコア補正は行いません。

| 項目 | 主分析 |

| 重複 | 同一銘柄・系列・参照安値の最初の警報、さらに21観測日のクールダウン |
| 将来期間 | 5・21・63観測日。主評価21 |

### スイングと警報の時点

ある価格が前後SPAN個の価格の**すべてより厳密に高い／低い**場合に高値／安値ピボットとします。同値がある窓はピボットにしません。欠損は一律補完せず、共通有効日へ絞ってから観測位置で計算します。同種ピボットを都合よく統合して未来情報を加えず、確定したものを記録します。

`pivot_date` は形成日、`confirmed_date` はSPAN観測日後、`signal_date` は確定済み参照安値を使った警報日です。未確定ピボットを過去へ適用しません。同じ日までの入力だけで計算しても、その日までの警報が変わらないことをテストします。

生の安値割れ日と、研究用に代表化したイベントを分けます。同じ参照安値の最初の警報を候補とし、その候補に21観測日のクールダウンを適用します。株価系列と相対価格系列の代表化は別々です。同一銘柄・日付に両系列のイベントがある場合の重複を隠さず、両系列を合わせた結果を独立例の単純な合計と解釈しません。

### モメンタムを混同しない

研究用モメンタムは共通有効日上の株価Pを用い、63・126・252価格観測値の端点リターンです。3か月は `P[i] / P[i-62] - 1` で、63リターン区間ではありません。株価系列の警報でも相対価格系列の警報でも、マッチングのモメンタム・ボラティリティは株価Pに基づきます。系列種別によって警報条件だけが変わります。

既存エンジンの市場横断日時インデックスと前方補完を使うモメンタムは、`engine_momentum_3m/6m/12m` として研究用 `momentum_3m/6m/12m` と区別します。最終日の保存スコアとの数値照合を `momentum_reproduction.csv` へ記録します。この工程で既存スクリーナー、選定、ウェイト計算は呼びません。共通日方式とエンジン方式が異なっても、定義差を隠して同じ指標とは扱いません。

## 将来評価と比較群

警報は当日終値で確定します。開始価格は次の有効日の終値、終了価格は**開始からH観測日後**です。例えばH=5なら警報位置i、開始i+1、終了i+6です。同日終値で事前売買できたものとはしません。これは警報確認後の将来変化の代理計測であり、執行可能な戦略収益ではありません。

株式とベンチマークの同一区間リターンを計算し、主な相対リターンは `(1+R_stock)/(1+R_benchmark)-1` です。単純差を出す場合は別の参考値です。将来データが足りなければそのホライズンを未観測として記録し、ゼロ埋めや全ホライズンからの一律削除はしません。集計の `right_censored_count` は将来不足、`excluded_influence_count` は既知異常の影響除外であり、別々に数えます。比較不能・警報日の価格欠損も同じ未観測理由へまとめません。

比較群は警報日tに利用できる情報だけで決めます。同日・同地域・同系列で確定参照安値があり、生の安値割れ状態ではない、本人以外の候補から選びます。繰り返し警報やクールダウンで代表イベントにならなかった安値割れ中の銘柄も対照に含めません。履歴条件と有限・正のボラティリティを満たす診断可能な断面で、株価Pの3か月モメンタムと直近ボラティリティを標準化します。ボラティリティは直近252リターンの標本標準偏差×√252なので、最低253価格観測値が必要です。

断面の母標準偏差（ddof=0、下限1e−12）をスケールに使います。両特徴で差がそれぞれ0.5標準偏差以内というカリパーを置き、許容内で標準化2次元距離が最小の1銘柄を選びます。同距離ではティッカー順で決めます。条件を満たさない場合は比較不能と記録します。対照銘柄の再利用は許容し、件数と依存性に注意します。未来リターンが存在する／有利かを見て対照を選びません。選択後の将来不足は、対照でも独立して未観測として扱います。

警報銘柄・対照銘柄それぞれと地域ベンチマークの共通有効日で将来期間を測ります。個別銘柄の欠損が違えば、同じ警報日とホライズンでも実際の評価開始・終了カレンダー日が異なる場合があります。各行の `entry_date` / `exit_date` を確認してください。区間の `max_drawdown` は開始日を含む価格経路の累積高値比で測り、開始価格からの最大下落 `min_return_from_entry` と区別します。

主な出力は、警報ありA、マッチした警報なしB、対応のあるA−B、3か月モメンタムのみの分類による比較です。特に3か月モメンタムがプラスの事例を主要サブ分析とします。平均、中央値、負リターン割合、対市場劣後割合、区間内下落、観測件数を読み、市場別・年別の件数差にも注意してください。

## 1306.Tの試験的補正と感度分析

対象は2026年3月30日・31日の1306.Tだけです。原本を深いコピーに取り、対象値を10倍します。前5有効日と後5有効日の価格（対象日を除く）の中央値をアンカーとし、元値／アンカーが**両日とも0.05〜0.2**の想定範囲にあることを確認します。補正後もアンカー比0.5〜2の連続性を確認します。既に補正済みと思われる値や想定外の値では停止し、二重補正を避けます。他銘柄の急変を自動で修復しません。

`correction_log.csv` に原値、補正値、日付、倍率、アンカー、理由を記録します。これは価格連続性による暫定修正で、公式調整済み価格との完全照合は未完了です。後から把握した品質修正を用いる探索的分析であり、当時のリアルタイム運用を再現したとは主張しません。

主仕様を固定したうえで、次を別の感度分析として比較します。

- スイング幅3・10。主分析は5のままです。
- 安値割れ閾値−1%・−3%。主分析は0%です。
- クールダウンなし（0観測日）。同一参照安値に対する最初の警報という代表化とは区別します。
- 補正なしの原価格。
- 補正なしの原価格で、分割影響期間を保守的に除外した場合。

影響除外は単に3月30日・31日のイベントを消すだけではありません。JPの警報・対照候補について、t時点の過去253共通価格観測値（252リターンの入力）または参照ピボットの判定窓が対象日と交われば除外します。マッチングに未来を使わず、選択後の各ホライズンでも開始〜終了の経路が対象日と交われば `excluded_influence` として区別します。将来の影響を見て都合のよい対照へ選び直しません。

感度分析で最も有利な結果を選んで「検証成功」としません。補正あり・なし・影響除外がどれだけ結論を変えるかを報告します。

## 不確実性と研究上の制約

マッチしたイベントの差について、銘柄を単位とするクラスターブートストラップと警報日付を単位とするクラスターブートストラップを別々に行います。クラスタ全体を復元抽出し、イベント数で重み付けした平均差の2.5・97.5パーセンタイルを保存します。両区間を包含する下限最小・上限最大のenvelopeも出しますが、これは依存構造への感度指標であり、較正された二方向クラスタ信頼区間ではありません。乱数seedと反復数もメタデータへ残します。少数事例やクラスタが少ない結果を、安定した推定とみなしません。

同一銘柄の複数警報、市場同時下落による日付集中、対照の再利用、評価期間重複があります。2種類のクラスタリングでも全依存性を完全に解消したとは言えません。全イベント独立を仮定した有意性や、因果効果を主張しません。

主比較で条件を合わせるのは3か月モメンタムとボラティリティです。6・12か月モメンタムは保存しますが、同時に完全調整しているわけではありません。対応差が観察されても、3・6・12か月指標のすべてを超える独立した予測力が証明されたとは解釈しません。

現在ユニバースを過去へ遡及するため、生存者バイアスがあります。SNDK・DELL・4062.Tは予備実験で事後選定され、一部の2026年の値動きも既に観察済みです。時間分割だけで完全な未観測検証にはなりません。本研究は探索的な後ろ向き分析です。真正なアウトオブサンプル評価は、ルール固定後に蓄積する新規データで別途行います。
